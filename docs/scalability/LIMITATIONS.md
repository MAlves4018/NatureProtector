# Scalability Limitations

- Results are local observed capacity only.
- Direct RabbitMQ temporal publishing is implemented through `TemporalLoadRunner`, but report-ready temporal conclusions require current live raw rows produced by the S16-R1 harness modes.
- Influx-disabled result is diagnostic A/B evidence, not a permanent recommendation to remove telemetry.
- No production or cloud autoscaling claim is made.
