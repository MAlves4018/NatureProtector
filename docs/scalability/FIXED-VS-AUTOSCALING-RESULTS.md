# Fixed vs Autoscaling Results

S16-R1 results are generated by:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/testing/Invoke-AutoscalingExperimentMatrix.ps1 -Mode TemporalComparison -BestFixedReplicas 3
python scripts/autoscaling/compile-scalability-temporal-comparison.py
```

The compiler writes:

- `WORKLOAD-COMPARISON.csv`
- `RESOURCE-COST.csv`
- `ELASTICITY-RESULTS.csv`
- `FIXED-VS-AUTOSCALING-REPORT.md`

Do not cite fixed-vs-autoscaling conclusions unless those files contain current raw rows for all required workload/topology/repetition cells.

`best-fixed` is an explicit harness parameter. For the current local S16-R1 evidence, use three replicas unless a later capacity campaign proves that four replicas has better capacity/efficiency and passes correction invariants.
