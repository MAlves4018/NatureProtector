# Defence Narrative

## Opening

Environmental systems do not only receive numbers; they receive numbers with origin, age, coverage and failure modes. NatureProtector explores how to preserve those boundaries through a controlled and auditable technical chain.

## Three-act structure

1. **The ambiguity problem** - absence, degradation and internal scores can be overinterpreted.
2. **The engineering response** - simulation, durable event processing, quality/eligibility, candidate assessment and evidence.
3. **The honest result** - a substantial experimental platform with explicit limitations, not an authorised warning system.

## Demonstration arc

Mission Control -> controlled run -> quality/eligibility -> evidence -> deployment gates -> limitations.
