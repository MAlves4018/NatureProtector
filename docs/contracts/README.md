# Contracts README

## Objetivo

Documentar o inventário e o processo de controlo de contratos usados no projeto, incluindo política de não alteração inadvertida.

## Política

- Contratos são fonte de verdade de integração.
- Alterações de contrato exigem versionamento explícito e plano de migração.
- Nesta fase de scaffolding, não são feitas alterações de contratos.
